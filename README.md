# Quotify 🌟

A random quote generator built with React. Pick a genre and get inspired.

## Features
- 3 genres: Romantic, Comedy, Life
- Dynamic background gradient per genre
- Fade animation on quote change
- Copy to clipboard
- Mobile responsive

## Tech Stack
- React
- Vite
- CSS3

## Getting Started

```bash
npm install
npm run dev
```
